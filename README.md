# GymLog — дневник тренировок

Учебный проект по дисциплине «Введение в интернет-технологии».

Вариант: **24 — Дневник тренировок** (группа Г «Учёт и статистика»).

Сайт для записи тренировок: упражнение, подходы, повторы, вес. Есть каталог упражнений с техникой выполнения и сводка за неделю.

## Как запустить

Открыть файл `site/index.html` в браузере.

## Что сделано

**ПР 1 — страницы, оформление, навигация**

- главная страница;
- каталог из 15 упражнений;
- отдельная страница для каждого упражнения (папка `site/exercises`);
- дневник: форма новой записи, итог за неделю и таблица последних записей;
- контакты и форма обратной связи;
- общий файл стилей `site/css/style.css`, Flexbox и Grid, сайт проверен на ширине 360 px;
- логотип и картинки упражнений нарисованы в SVG.

Формы пока не работают (будет в ПР 2), данные в дневнике примерные.
