# GymLog — дневник тренировок

Учебный проект по дисциплине «Введение в интернет-технологии».

Вариант: **24 — Дневник тренировок** (группа Г «Учёт и статистика»).

Сайт для записи тренировок: упражнение, подходы, повторы, вес. Есть каталог упражнений с техникой выполнения, регистрация и вход, у каждого пользователя свой дневник и сводка за неделю.

## Как запустить

Нужен Python 3.9 или новее.

```
cd gymlog
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload
```

Открыть в браузере: http://127.0.0.1:8000

База данных `gymlog.db` создаётся сама при первом запуске, в неё сразу добавляются 15 упражнений. Чтобы начать с чистой базы, остановите сервер (Ctrl + C) и удалите файл `gymlog.db`.

Для Windows вместо `source venv/bin/activate` нужно `venv\Scripts\activate`.

## Что сделано

**ПР 1 — страницы, оформление, навигация**

- главная, каталог, страница упражнения, дневник, контакты;
- общий файл стилей `site/css/style.css`, Flexbox и Grid, сайт проверен на ширине 360 px;
- логотип и картинки упражнений нарисованы в SVG.

**ПР 2 — JavaScript и внешние данные**

- весь код в файле `site/js/script.js`;
- формы проверяют поля, ошибки пишутся под полем;
- в каталоге работают поиск, фильтр по группе мышц и сортировка;
- на главной показывается погода в Санкт-Петербурге с сайта Open-Meteo, если интернета нет — выводится сообщение об ошибке.

**ПР 3 — сервер, база данных, вход**

- сервер на Python + FastAPI (`main.py`), база SQLite (`database.py`);
- каталог, главная, страница упражнения и дневник берут данные с сервера;
- вместо 15 отдельных страниц упражнений теперь одна `exercise.html?id=...`;
- регистрация и вход (страница `login.html`), пароль хранится только в виде хеша (библиотека bcrypt);
- после входа в дневнике видны только свои записи, новые записи сохраняются в базу;
- все SQL-запросы параметризованные (значения передаются через `?`).

## Структура базы данных

Три таблицы. Записи дневника связаны с пользователем и с упражнением.

```
users 1 ──── * records * ──── 1 exercises
```

**users** — пользователи

| Поле | Тип | Описание |
| --- | --- | --- |
| id | INTEGER | первичный ключ |
| name | TEXT | имя |
| email | TEXT | почта, уникальная |
| password_hash | TEXT | хеш пароля (bcrypt) |

**exercises** — упражнения (15 записей)

| Поле | Тип | Описание |
| --- | --- | --- |
| id | INTEGER | первичный ключ |
| name | TEXT | название |
| muscle | TEXT | группа мышц для фильтра (legs, chest, back, shoulders, arms, core) |
| muscle_name | TEXT | группа мышц по-русски |
| level | INTEGER | сложность: 1 — новичок, 2 — средний, 3 — опытный |
| description | TEXT | описание |
| main_muscles | TEXT | основные мышцы |
| extra_muscles | TEXT | дополнительные мышцы |
| equipment | TEXT | снаряжение |
| recommendation | TEXT | рекомендуемые подходы и повторы |
| steps | TEXT | шаги техники (через перенос строки) |
| mistakes | TEXT | частые ошибки (через перенос строки) |
| image | TEXT | файл картинки |
| image_alt | TEXT | описание картинки |

**records** — записи дневника

| Поле | Тип | Описание |
| --- | --- | --- |
| id | INTEGER | первичный ключ |
| user_id | INTEGER | чья запись, ссылка на users.id |
| exercise_id | INTEGER | упражнение, ссылка на exercises.id |
| date | TEXT | дата в формате ГГГГ-ММ-ДД |
| sets | INTEGER | подходы |
| reps | INTEGER | повторы |
| weight | REAL | вес в кг, может быть пустым |

## Обработчики (API)

| Метод и адрес | Что делает |
| --- | --- |
| GET /api/exercises | список всех упражнений |
| GET /api/exercises/{id} | одно упражнение, если такого нет — 404 |
| POST /api/register | регистрация (имя, почта, пароль), после неё сразу вход |
| POST /api/login | вход (почта, пароль), неверные данные — 401 |
| POST /api/records | новая запись (упражнение, дата, подходы, повторы, вес), без входа — 401 |
| GET /api/records | записи только текущего пользователя, без входа — 401 |

Первые пять обработчиков требует задание. Шестой нужен, чтобы после входа пользователь видел свои записи. Чтобы войти под другим пользователем, достаточно войти заново на странице «Вход».

Описание всех обработчиков с возможностью их попробовать открывается по адресу http://127.0.0.1:8000/docs
